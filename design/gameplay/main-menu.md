# Main Menu

- **Callsign:** the name used on the [Leaderboard](../online/leaderboard.md). A random one is filled in the first time; edit it any time (2–16 letters, numbers, spaces or hyphens).
- **Continue** appears when a save exists.
- **New Game** starts a fresh galaxy. It asks for confirmation if it would overwrite a save.
- **Join with code:** enter a captain's 5-character room code to fly as an [escort](../online/escorts.md).
- **Leaderboard** opens Lane Records.
- **Sound On/Off** toggle.
- A short How to Play panel with the controls.

A new game starts with **60 credits**, the starting ship and the Pulse Laser.
