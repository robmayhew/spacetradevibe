# Victory

Delivering the shutdown code to the Terminus shows the **KL9 CORE SHUT DOWN** victory screen ("The KL9 go dark, and Mulerebs is free") with your stats: deliveries, credits earned, kills, bosses destroyed, ships lost, systems visited and **run time**, followed by the **score** breakdown (see [Leaderboard](../online/leaderboard.md#score)).

Enter or confirm your callsign and press **Submit** to post the run to Lane Records. Runs can't be posted if:

- the run time is under 3 minutes,
- the save started before the run clock existed, or
- the [test console](../foundations/test-console.md) was used (a test run).

From there you can **Keep flying** on the same save or go to the main menu.
