# Story in the Game

The [Story](../game.md#story) in a few lines: you fly for **Mulerebs** against the **KL9** robot army, carrying a shutdown code to their core at the **Terminus**. The KL9 can only attack at warp.

| Story point | Where it shows up |
| --- | --- |
| Home world **Mulerebs** | Your starting system is always named Mulerebs; hovering it on the [star map](gameplay/station-screen.md#star-map) says "Your home world." |
| The **KL9 robot army** | Every enemy is a KL9 robot with a glowing red sensor eye. Banners name them: "KL9 ambush at warp", "KL9 capital ship inbound". See [Enemies](enemies/enemies.md). |
| **The KL9 can only attack at warp** | Travel between stations is warp: the HUD reads "AT WARP", warp streaks rush past, undocking says "Engaging warp", and arrival says "Dropping out of warp". Stations and docking have no KL9 attacks. See [Travel & Combat](gameplay/travel-and-combat.md). |
| A ship with **minimal weapons** | You start with only the Pulse Laser and a stock hull. See [Weapons](ship/weapons.md). |
| **Trade and gather technologies** | Contracts pay for upgrades and new weapons at stations. See [Systems](ship/systems.md). |
| The **shutdown virus code** | The cargo on the final route is the **KL9 Shutdown Code**. See [Route Difficulty & Economy](world/route-difficulty-and-economy.md). |
| The **Terminus**, heart of the KL9 | The contract card and star map call it "The KL9 core". The route there always has 5 waves and a KL9 capital ship. |
| **Free your people** | The victory screen reads "KL9 CORE SHUT DOWN: … The KL9 go dark, and Mulerebs is free." See [Victory](world/victory.md). |

The menu tagline, How to Play panel and the new-game briefing ("For Mulerebs") retell the story in short.
